# Contributions and AI policy

This is an independent educational sandbox, not an upstream Ruff project.
Do not submit bot-generated comments, patches, or recommendations directly to
`astral-sh/ruff`; upstream's own AI policy and human review requirements apply.

AI assistance is permitted for sandbox authoring, but the named human repository
owner is responsible for inspecting the configuration, testing it, validating
references, and disclosing AI involvement. Generated issue comments are advisory
and never authority to close, merge, assign, label, or implement a change.
No AI-produced code or issue response should be submitted upstream unchanged.
AI output must be checked against source evidence, reproducible cases and the
time cut-off before human adoption. Suspected security disclosures are not
processed automatically; use the upstream private disclosure process.

Changes to agent configuration require human review, a new lockfile compilation,
and rerunning the golden cases. Do not add repository-wide write permissions or
unreviewed external MCP servers.
